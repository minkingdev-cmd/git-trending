# Repo Languages ★ 辅指标
无匹配仓库
试试减少标签、切换 OR，或清空关键词

本版修订

  • 多语言：每个 repo 为 languages: [{name, pct}, …]（占比之和 ≈ 100）；行内色条 + 名称/百分比；+N more 可展开。
  • 语言筛选：顶部可多选；仓库含任一所选语言即匹配（OR）。点行内语言可快捷筛选。
  • 趋势：仅 Repo 旁 📈 打开历史弹层；无列表末列 sparkline。
  • 添加仓库：右上角「＋ 添加仓库」；解析 owner/name 或 GitHub URL → 预览 → 加入跟踪；见「我的跟踪」。
  • 主题：Light / Dark；localStorage 键 ght-theme。
  • 布局：全宽 + min-width: 960px；介绍默认显示。
